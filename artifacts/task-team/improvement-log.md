# 개선 기록: 실제 도시 API 연동 사이클

## 2026-11-09 인계 후 관찰

- 전체 최신 PR과 사용자 작성/작업 PR의 의미를 혼동하고 Assignee까지 확대해 불필요한 재질문을 했다. 사용자 맥락과 실제 PR 작성자·화면을 먼저 대조한다.
- 외부 리뷰가 경로 접두어와 모달 경계를 추정으로 결함 판정했다. 운영 실측 계약과 설치된 Radix의 포인터·포커스 차단을 대조해 기각했고 회귀 테스트로 확인했다.
- `Number()`가 잘못된 외부 값을 좌표 0으로 바꾸는 결함을 QA가 재현했다. 외부 응답도 변환 전에 자료형·빈 값을 확인한다.
- CodeRabbit의 미추적 전체 전송은 자동 승인 검토에서 거부됐다. 사용자 외부 전송 승인 후에도 범위가 넓어 거부되어, 필요한 테스트 경로만 명시 staging하고 일반 uncommitted 리뷰로 신규 테스트를 포함했다.
- 신규 UI 테스트의 정확 라벨 일치와 Radix mouse-down 생략으로 실패가 반복됐다. 실제 라벨의 필수 표시·컴포넌트 이벤트 계약을 읽고 같은 패턴을 함께 수정한다.
- 검증 명령은 로그 파일에 저장해 출력 한도로 결과를 놓치지 않는다. 성공한 build는 테스트만 바뀐 뒤 반복하지 않았다. pnpm sandbox 버전 전환 fetch 실패와 앱 검사 실패는 구분했다.
- D-2의 제외 권장안을 사용자 승인으로 잘못 해석했다. 사용자 질문 후 승인 근거 부재를 확인하고 실제 중복 누락을 보고, 보완/보류 결정을 요청했다. 명세 권장안·사용자 결정·실행 결과를 구분한다.

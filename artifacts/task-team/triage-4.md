## 사용자 지적 후 정정

D-2의 “이번 범위에서 제외”는 디자인 명세의 권장안이며 사용자 승인 기록이 확인되지 않았다. N-1의 국가명 표기 변경 승인을 중복 누락 위험의 수용 승인으로 해석할 수 없다. 아래의 D-2 제외 판정은 철회하며, 실제 QA로 재현된 결함의 보완/보류를 사용자에게 보고하고 결정 대기한다.

## 코드 리뷰

- High 운영 URL 중복: **SKIP**. 문자열 조합 결과 자체는 맞지만 잘못된 경로라는 결론은 근거와 반대다. `00-input.md` 2차 확인된 사실(107~115행)은 운영 기준 주소 뒤 `/api/v1/cities/all`을 붙인 요청의 200 응답과 `/api`를 뺀 경로의 404를 기록한다. `api-spec.md` 2-B(279~284행)도 운영 base가 `/api`로 끝나며 문자열로 접미 경로를 붙이도록 명시한다. `cityUpstream.ts:96`은 이 계약을 따른다. 이번 세션은 실서버 요청을 재실행하지 않았으며 기존 실측 기록과 현재 명세를 근거로 판단했다. QA에서 가짜 주소를 이용한 URL 조합 회귀 검사 필요.
- Medium 모달 중 탭 전환: **SKIP**. `TabsTrigger` 자체에 disabled는 없지만 사용자 접근을 막는 수단이 이미 있다. `src/components/common/Dialog.tsx`는 Radix Root의 기본 modal 설정을 사용한다. 설치된 `@radix-ui/react-dialog`의 `dist/index.mjs:33,152-153`은 기본 `modal=true`, 열린 동안 `trapFocus`와 `disableOutsidePointerEvents`를 적용한다. 강제로 이벤트 핸들러를 호출하는 상황을 실제 사용자 경로로 보지 않는다. 이전 handoff에도 모달 중 탭 클릭 불가 실측 기록이 있다. QA에서 포인터와 키보드 경계 확인 필요.
- 국가명 변경과 중복 사전 검사: **VALID**, 사용자 미결정. 디자인 D-2는 권장안이며 제외 승인 근거가 아니다. QA 재현 후 사용자 결정 필요.

## 보안 리뷰

차단 finding 없음. HTTP 개발 상류의 조건부 전송 위험은 기존 사용자 지정 계약에 속하며 실제 환경을 이번 세션에서 확인하지 않았다. 운영 쓰기 403, 인증, 국가·좌표 경계를 QA로 넘긴다. 보안 리뷰의 배포 승인 문구는 보안 검토 판정이며 실제 배포나 전체 QA 완료를 뜻하지 않는다.

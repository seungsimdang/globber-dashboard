# T09 QA 보고서 2 — 도시 API 2·3차

> 보완 전 기록. 최종 후속 결과는 `qa-report-3.md`: D-2·단일 로딩 보완, 전체 183개 및 lint·타입·build 통과.

## 사용자 지적 후 범위 정정

아래의 “D-2 범위 제외”는 디자인 권장안에 근거한 당시 분류이며 사용자 승인 기록은 확인되지 않았다. 실제 중복 누락을 사용자가 수용했다고 판단하지 않는다. 이후 사용자가 이번 작업 보완을 승인해 도시명+국가코드 비교로 수정했다. 실패 재현 및 자동 테스트 179개 통과 결과 자체는 동일하다.

## 판정

**최초 품질 판정: 조건부 실패(별도 qa-report-3.md와 구분).** 요구사항의 서버 분리·운영 쓰기 차단·국가 검색·지오코드 경계는 모킹 테스트로 통과했다. 다만 디자인 명세 D-2가 이번 범위에서 제외한 국가명 표기 차이의 중복 누락을 실제 mutation 경로에서 재현했다. 이 위험은 사용자가 요청하지 않은 로직 변경을 하지 않고 남겼다. 실서버·Nominatim·브라우저 동작은 이번 QA에서 검증하지 않았다.

## 실패 및 잔여 위험

### D-2 국가명 표기 차이에 따른 중복 누락 — 실패

`implementation-5.md`의 “기존 국가명과 Intl 이름이 달라 같은 도시를 놓칠 수 있음” 항목을 실제 `useAddCityMutation` 경로에서 확인했다. 캐시에 `Seoul / South Korea`가 있고 새 입력이 `Seoul / 대한민국`이면 사전 검사가 중복으로 판정하지 않고 `addCity("dev", ...)`를 호출한다. 이는 `design-spec.md` D-2에서 이번 범위 밖으로 명시한 위험이지만, 데이터 중복 요청이 발생할 수 있으므로 QA 판정에는 실패로 남긴다. 구현 로직은 수정하지 않았다. 상류 서버가 최종 중복을 거부하는지는 확인하지 않았다.

### Code Review 4 재검토 항목

- 운영 경로 중복 finding은 `triage-4.md` 결정대로 **SKIP**. 가짜 base URL 테스트는 명세에 적힌 `/api` 포함 기준 주소 뒤 접미 경로 결합을 확인했다. 실제 운영 서버 응답은 재검증하지 않았다.
- 모달 중 탭 전환 finding은 `triage-4.md` 결정대로 **SKIP**. Radix modal의 포인터/포커스 차단을 jsdom에서 확인했고, 이 동작과 상반되는 재현은 없었다. 실브라우저 키보드·시각 확인은 미검증이다.

## 실행·범위 메모

- 신규 테스트는 `tests/` 아래에 두었고 검증 대상 소스 모듈·컴포넌트를 실제 import 후 호출한다. 테스트 로직을 복사해 검증하지 않았다.
- 추가·수정한 테스트 파일: `tests/app/api/cities/route.test.ts`, `tests/app/api/cities/cityId/route.test.ts`, `tests/app/api/geocode/route.test.ts`, `tests/components/CitiesPageContent.test.tsx`, `tests/components/CityFormGeocode.test.tsx`, `tests/components/CountryCombobox.test.tsx`, `tests/hooks/useCityMutations.test.tsx`, `tests/lib/server/cityServer.test.ts`, `tests/lib/server/geocode.test.ts`, `tests/services/cityService.test.ts`.
- 잘못된 좌표 형식의 실패 재현 뒤 구현 담당자가 실제 `src/lib/server/geocode.ts`에 숫자 문자열/숫자 형식 가드를 추가했고, QA는 해당 모듈을 import하는 좌표 회귀 테스트로 수정 후 통과를 확인했다. QA는 구현 코드를 수정하지 않았다.
- 실서버 도시 쓰기와 실제 Nominatim 요청은 실행하지 않았다.
- 브라우저 인증은 시도하지 않았다. 현 브라우저가 `/login`으로 이동한다는 작업 인계 상태와 코드 기반 jsdom 검증을 실제 브라우저 증거로 간주하지 않았다.
- TaskUpdate 도구는 제공되지 않아 상태 갱신을 수행하지 않았다.
